Обробка команд

Шлях повідомлення від Telegram до відповіді: dispatch у MessageHandler, перевірка ролі в Command, виконання через Clean Architecture шари.

DISPATCH

MessageHandler маршрутизує

  • Кожна команда реєструється в MessageHandler
  • Невідомі команди ігноруються без помилки
  • Dispatch за текстом команди — рядковий match

Перевірка ролі

  • Command.execute() перевіряє роль через MemberService
  • hasAdminAccess() / hasModeratorAccess() → DB
  • DENIED: відповідь без виклику Controller

Clean Architecture flow

Controller збирає CommandResponse, Service виконує бізнес-логіку, Repository звертається до DB. Command надсилає підсумкову відповідь через TelegramBot.
